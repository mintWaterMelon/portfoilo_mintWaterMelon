# 이영준 개발자 포트폴리오

React + Vite 기반 다크 모드 포트폴리오입니다.
프로젝트 중심으로 `UV Manager`와 `WBC Counting Project`를 소개합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소로 접속하면 됩니다.

## PDF 저장

화면 오른쪽 아래의 `PDF로 저장` 버튼을 누르거나 브라우저 인쇄 기능에서 PDF로 저장하면 됩니다.

## 수정 위치

- 프로필/연락처: `src/app/components/Header.tsx`
- 자기소개: `src/app/components/About.tsx`
- 프로젝트 내용: `src/app/App.tsx`
- 프로젝트 카드 UI: `src/app/components/ProjectCard.tsx`
